# SELF//CTRL

Personal "Human Digital Twin" decision-intelligence web app powered by Google Gemini.

## Deploy on Vercel
1. Import this GitHub repo in Vercel (Framework preset: **Other**, no build command).
2. Add environment variable `GEMINI_API_KEY` (your Google AI Studio key).
3. Redeploy. The key stays on the server, so every visitor can use the app without entering one.

Never commit an API key or a `.env` file to this repo.
